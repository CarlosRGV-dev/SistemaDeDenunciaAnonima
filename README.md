# SistemaDeDenunciaAnonima
Criação de uma pagina online para fazer denuncias online. 

O Sistema de Denúncias Anônimas da PMESP foi desenvolvido para permitir que cidadãos registrem ocorrências de forma segura, rápida e confidencial. O objetivo é fortalecer a colaboração entre a população e as autoridades, facilitando o combate a irregularidades, crimes e situações de risco. A plataforma garante o anonimato do denunciante e possibilita o acompanhamento do andamento da denúncia por meio de um número de protocolo exclusivo.
